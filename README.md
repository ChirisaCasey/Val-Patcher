# Val-Patcher
## Initial Setup
1. Copy the shortcut for valorant to the main directory
2. Enter the directory for your VALORANT folder in path.txt

## Usage
Copy any video file into the *"Custom"* folder.

Run Launcher.bat and wait till its done loading.

if valorant was run before the launcher, it will patch the current instance of valorant.
otherwise, it will patch and launch valorant automatically. 

click any key after selecting the launcher window to run the exit valorant function

IMPORTANT: Do not exit the launcher after patching via the exit button, only use the intended exit functionality, otherwise valorant will automatically unpatch itself on the next run.

sidenote: valorant will only be patched when running on the launcher.
